# Part A: Practical Exercises

## Exercise 1 — Build acquisition systems through source taxonomy (structured-semi-structured-document-physical categories)
**Scenario:** provide a realistic alternative data analytics scenario appropriate to the audience (real or closely modeled on documented practice).
**Objective:** build acquisition systems through source taxonomy (structured-semi-structured-document-physical categories), scraping craft (HTML analysis, extraction patterns, robustness engineering, anti-scraping navigation), API integration (documentation literacy, client patterns, version awareness, bulk-incremental strategies), infrastructure engineering (schedulers, storage design, monitoring, scaling), source evaluation (coverage assessment, reliability testing, redundancy design, cost-benefit integration), legal-ethical boundaries (ToS compliance, personal-data avoidance, licensing, access respect), and operations practice (calendar management, raw archives, quality gates, documentation), avoiding brittle scraping, rate violations, quota blindness, raw-data discarding, ToS gambling, and undocumented hoarding failures.
**Constraints:** must use the framework taught in the corresponding unit; must state assumptions and trade-offs; one deliverable, length-bounded.
**Deliverable:** the professional artifact this capability produces (memo, table, plan, analysis, or model — as applicable).
**Evaluation criteria:** correct application of the framework; decisions justified with evidence; limitations honestly stated; artifact usable by a colleague without further explanation.

## Exercise 2 — Integrated capstone
**Scenario:** one realistic problem spanning the whole section.
**Objective:** take the problem through every unit's framework in sequence.
**Constraints:** all unit artifacts required and internally consistent; evidence discipline maintained throughout.
**Deliverable:** a coherent campaign/portfolio document assembled as real professional documentation.
**Evaluation criteria:** consistency across artifacts; each capability demonstrably exercised; trade-offs stated at each decision point.
