# Part A: Practical Exercises

## Exercise 1 — Program for alternative data through language and ecosystem selection (Python dominance rationale
**Scenario:** provide a realistic alternative data analytics scenario appropriate to the audience (real or closely modeled on documented practice).
**Objective:** program for alternative data through language and ecosystem selection (Python dominance rationale, R complement, environment discipline, tool pragmatism), data manipulation core (dataframe mastery, time-series handling, missing-data management, large-data techniques), acquisition programming (HTTP-API literacy, scraping toolkits, format fluency, database integration), geospatial and scientific computing (spatial libraries, numerical foundations, image processing, statistics libraries), analysis practice (exploratory workflows, visualization, reproducibility, reporting integration), engineering quality (version control, testing, organization, performance), and skill development (application learning, code reading, community navigation, T-shaped growth), avoiding notebook spaghetti, environment fragility, manual repetition, memory overflow, untested pipelines, and tutorial perpetuity failures.
**Constraints:** must use the framework taught in the corresponding unit; must state assumptions and trade-offs; one deliverable, length-bounded.
**Deliverable:** the professional artifact this capability produces (memo, table, plan, analysis, or model — as applicable).
**Evaluation criteria:** correct application of the framework; decisions justified with evidence; limitations honestly stated; artifact usable by a colleague without further explanation.

## Exercise 2 — Integrated capstone

**Objective:** take the problem through every unit's framework in sequence.
**Constraints:** all unit artifacts required and internally consistent; evidence discipline maintained throughout.
