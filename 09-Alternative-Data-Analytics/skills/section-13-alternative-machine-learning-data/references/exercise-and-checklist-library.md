# Part A: Practical Exercises

## Exercise 1 — Apply machine learning to alternative data through landscape literacy (problem-type mapping
**Scenario:** provide a realistic alternative data analytics scenario appropriate to the audience (real or closely modeled on documented practice).
**Objective:** apply machine learning to alternative data through landscape literacy (problem-type mapping, ML-statistical judgment, data-regime awareness, capability honesty), supervised toolkits (regularized regression, tree ensembles, neural networks, selection discipline), unsupervised and specialized methods (clustering, dimensionality reduction, computer vision, NLP deployment), time-series integration (feature engineering dominance, temporal validation, ensemble forecasting, drift handling), interpretation discipline (explainability toolkits, plausibility review, robustness testing, baseline requirements), production systems (pipeline integration, drift monitoring, retraining governance, reproducibility), and frontier practice (foundation models, automated discovery, research tracking, tooling evolution), avoiding complexity escalation, leakage blindness, black-box deployment, baseline skipping, retraining chaos, and LLM hype failures.
**Constraints:** must use the framework taught in the corresponding unit; must state assumptions and trade-offs; one deliverable, length-bounded.
**Deliverable:** the professional artifact this capability produces (memo, table, plan, analysis, or model — as applicable).
**Evaluation criteria:** correct application of the framework; decisions justified with evidence; limitations honestly stated; artifact usable by a colleague without further explanation.
